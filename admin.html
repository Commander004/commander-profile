نوع پس‌زمینه

Default → وقتی چیزی تنظیم نکردی، گرادیانتم تیره پیش‌فرض نمایش داده می‌شود.
آپلود → عکس، GIF یا ویدیو از دستگاه یا با URL.

انتخاب نوع رسانه

⚠️ الزامات ویدیو پس‌زمینه (حتماً رعایت کن):

• رزولوشن پیشنهادی: 1920 × 1080 (Full HD)
• یا برای موبایل سبک‌تر: 1280 × 720
• نسبت تصویر: ۱۶:۹
• فرمت: MP4 (H.264) — ترجیحاً
• حجم ایده‌آل: کمتر از ۸ تا ۱۰ مگابایت
• ویدیوهای خیلی بزرگ روی موبایل کند یا داغ می‌کنند

فایل را داخل پوشه assets/videos/ بگذار و مسیر نسبی وارد کن
(مثال: assets/videos/my-bg.mp4)

نکته GitHub Pages: آپلود مستقیم به سرور نیست. فایل را در ریپو بگذار (assets/images/ یا assets/videos/)، بعد مسیر نسبی را وارد کن. برای پیش‌نمایش فوری می‌توانی از «انتخاب فایل» استفاده کنی.
