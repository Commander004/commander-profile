# 🎛️ Commander Profile

An advanced personal profile / dashboard page with radio, lyrics, and multiple sections. Built with pure CSS and modern frontend techniques.

صفحه پروفایل و داشبورد پیشرفته شخصی با قابلیت رادیو، نمایش متن آهنگ (lyrics) و بخش‌های متعدد. ساخته‌شده با CSS خالص و تکنیک‌های مدرن فرانت‌اند.

---

## ✨ Features / ویژگی‌ها

**English:**
- Multi-section profile/dashboard
- Radio player module
- Lyrics display
- Responsive design
- Modular CSS architecture (`core`, `dashboard`, `radio`, `lyrics`, `responsive`)
- Heavy use of assets (images, possibly videos)

**فارسی:**
- پروفایل/داشبورد چندبخشی
- ماژول پخش‌کننده رادیو
- نمایش متن آهنگ (Lyrics)
- طراحی ریسپانسیو
- معماری CSS ماژولار
- استفاده سنگین از assets
